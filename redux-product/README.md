## About the Project

This project demonstrates how to integrate **Redux** into a modern React application.  
It includes a complete flow covering API requests, global state management, and UI updates based on store data.

The application retrieves a list of products from an external API and uses Redux to manage product details, selection, and internal storage.  
It is designed as a lightweight reference for developers learning state management patterns in real-world scenarios.

Key concepts highlighted include:

- Managing global state with Redux Toolkit
- Creating slices for structured state and reducers
- Handling async operations using Redux Thunk
- Connecting React components using `useSelector` and `useDispatch`
- Maintaining clean and scalable project structure

## Tech Stack

- **React 19** — Component-based UI development
- **Redux / Redux Toolkit** — Centralized and predictable state management
- **Tailwind CSS** — Utility-first styling for rapid UI development
